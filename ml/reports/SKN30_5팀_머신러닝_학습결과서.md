# 머신러닝 / 딥러닝 모델 학습 (ML / DL Training)

## 1. 개요

- **목표** : 전일까지의 정보만으로 해당 날짜의 운동 기록 존재 여부를 예측하고, **웨어러블 신호가 앱 운동 이력 대비 추가 정보를 주는지** 오프라인에서 검증
- **문제 정의** : Whoop 합성 데이터(100,000행 / 286명 / 2023-01-01~2024-02-03 / 39컬럼)에서 `workout_completed`(당일 운동 기록 존재 = 1) 이진 분류. 기저율 0.5401
- **사용 프레임워크** : scikit-learn 1.9.0, pandas 2.3.3, numpy 2.5.2, pyarrow 21.0.0, joblib 1.5.3, matplotlib 3.10.5

> **딥러닝 미사용 (의도적 설계)** — 39개 컬럼 표 형식 데이터이므로 `ml/AGENTS.md` 1절에서 GBDT 계열로 범위를 한정했다. 표 형식 이진 분류에서 GBDT 대비 DL의 이점이 확인되지 않으며, 재현성·해석성·심사 가능성을 우선했다. 본 결과서의 모든 실험은 ML 계열이다.

> **적용 범위 한정** — 합성 데이터 기반 **오프라인 분석 전용**이다. 제품 런타임·알림·에이전트 의사결정에 연결하지 않는다 (`ml/models/MODEL_CARD.md` 사용 금지 절).

### 2.2 모델 비교 기준

| 비교 지표 | 산출식 / 측정 대상 | 목표값 | 비고 |
|---|---|---|---|
| **PR-AUC** | Precision-Recall 곡선 하부 면적 | **A2-lag1 참조선(0.6237) 초과** | **최종 선정 지표** |
| ROC-AUC | 임계값 무관 순위 성능 | A0(0.5000) 초과 | 보조 지표 |
| Precision / Recall | 임계값 0.5 기준 | 절대 기준 미설정 | 임계값 의존 |
| F1 | Precision·Recall 조화평균 | 절대 기준 미설정 | 임계값 의존 |
| **Brier** | 확률 예측 평균제곱오차 | 낮을수록 우수 | **확률 신뢰도** |
| Calibration curve | 10-bin 예측확률 vs 실제빈도 | 대각선 근접 | 확률 해석 가능성 |
| **세그먼트 성능** | 이력 길이(0-7/8-28/29+), 경험 등급 | **구간 간 편차 확인** | **서비스 적합성 판단 근거** |

> **정확도(Accuracy)를 주지표로 쓰지 않았다.** 기저율 0.5401에서 다수 클래스만 찍어도 정확도 0.5401이 나오므로 변별력이 없다. PR-AUC를 선정 지표로, Brier·calibration을 확률 신뢰도 지표로 사용했다.
>
> **사전 정의된 절대 목표값을 두지 않았다.** 합성 데이터의 달성 가능 성능을 사전에 알 수 없어, 절대 수치 대신 **A0(다수 클래스)와 A2-lag1(자기상관) 두 참조선 초과**를 판정 기준으로 삼았다.

```

  │      · 전기간 상수 2개 (hrv_baseline·rhr_baseline — 미래정보 + 사용자 지문)
  │      · 정책 제외 5개 (age·gender·신체정보) / 분산 0 : 1개
  │
  ├─[2] 인과적 피처 생성 ── prepare_data.py
  │      · user_id + local_date 정렬 후 컨디션 값 shift(1)
  │      · 7일·28일 롤링은 사용자별 시간순 (미래값 미포함)
  │      · 결측을 0으로 채우지 않음 (미착용과 "값 0"은 다름)
  │
  ├─[3] 분할 (무작위 분할 미사용)
  │      · 시간 기반 70/15/15 → 79,652 / 14,966 / 5,382
  │      · 사용자 기반 70/15/15 → 69,956 / 15,088 / 14,956 (200/43/43명)
  │
  ├─[4] 실험 매트릭스 38개 = 2개 분할 × (6 ablation × 3 모델 + A0 분할당 1회)
  │      → validation 으로만 평가. 실험 로그에 test 미등장
  │
  ├─[5] 선정 : validation PR-AUC 최고 (A5 제외) → time_A3_histgb 동결
  │      → final_model.yaml 에 SHA-256 봉인
  │
  ├─[6] 재학습 : train + validation 94,618행
  │
  └─[7] test 1회 평가 ── final_evaluate.py
         → 배타적 생성 가드로 재평가 차단, 재선정 없음
```

### 3.1 실험 결과 비교

**최종 선정 모델 : `time_A3_histgb` — HistGradientBoostingClassifier + A3 피처 19개 (시간 분할)**

|---|---|---|---|---|---|
| learning_rate | 0.1 | 미탐색 (고정) | sklearn 기본값 | HistGB | 아래 註 |
| max_iter | 300 | 미탐색 (고정) | 3개 모델 동일 예산 | HistGB | |
| random_state | 42 | — | 시드 고정 | 전체 | 재현성 |
| n_estimators | 300 | 미탐색 (고정) | HistGB `max_iter`와 동일 | RandomForest | |
| min_samples_leaf | 5 | 미탐색 (고정) | 과적합 방지 | RandomForest | |
| max_iter | 1000 | 미탐색 (고정) | 수렴 보장 | LogisticRegression | |
| 판정 임계값 | 0.5 | 미탐색 | 평가 표준값 | 전체 | **제품 규칙 아님** |

> **註 — 하이퍼파라미터 탐색을 수행하지 않았다.** Grid/Random Search 없이 세 모델 모두 사전 고정값을 사용했다. 실험 예산 전량을 **피처 ablation × 분할 매트릭스(38회)** 에 배분했다. 본 과제의 질문이 "성능 최대화"가 아니라 **"어떤 피처 블록이 실제로 기여하는가"** 였기 때문이다. 성능 극대화가 목표라면 튜닝이 남은 개선 여지다.

**세그먼트 분석 — 서비스 적합성 판단의 핵심**

| 경험 등급 | 표본 (test) | 양성률 | PR-AUC | 구간내 ROC-AUC | 임계값 0.5 양성판정 |
|---|---:|---:|---:|---:|---:|
| BEGINNER | 1,145 (21%) | 0.331 | **0.3853** | 0.5666 | **0건** |
| INTERMEDIATE | 1,914 (36%) | 0.443 | 0.5293 | 0.6073 | 486 |
| ADVANCED | 2,323 (43%) | 0.728 | 0.8528 | 0.6901 | 2,317 |

| 이력 길이 | 표본 | 양성률 | PR-AUC | Brier |
|---|---:|---:|---:|---:|
| 0-7일 | 344 | 0.544 | 0.6732 | 0.2305 |
| 8-28일 | 903 | 0.550 | 0.7253 | 0.2215 |
| 29일+ | 13,841 | 0.550 | 0.7447 | 0.2125 |

> 시간 분할의 validation/test는 전 행이 `29+`여서 콜드스타트 측정이 불가능하다. 위 이력 표는 **최종 모델과 동일 구성(A3 + HistGB)** 을 사용자 분할 **validation**에서 측정한 값이다. test 재접근이 아니다. 콜드스타트 저하는 0.7447 → 0.7253 → 0.6732로 완만하다.

**관측된 3가지 한계**

1. **정적 속성이 성능 대부분을 설명한다.** A0→A3 총 상승분 0.2281 중 **A1(정적 3개)이 0.1869로 81.9%** 를 차지한다. 운동 이력 9개는 +0.0398, 웨어러블 7개는 **+0.0013**에 그쳤다. permutation importance에서도 `experience_level_code`가 0.1017로 2위 `day_of_week`(0.0526)의 약 2배다. → **이 합성 데이터셋에서 서비스 수집 웨어러블의 뚜렷한 추가 기여는 관측되지 않았다.**

2. **경험 등급 게이팅.** BEGINNER 구간에서 임계값 0.5 양성 판정이 **0건**이며, 시간 test(PR-AUC 0.3853 / 기저 0.331)와 사용자 validation(0.3162 / 기저 0.270) **두 독립 분할에서 동일하게 재현**된다. 이력 29일 이상인 초보자도 0건이므로 **콜드스타트 문제가 아니라 경험 등급 자체에 대한 게이팅**이다. 구간내 ROC-AUC가 0.57~0.69로 모두 낮은 것과 일관된다. → **단일 임계값을 제품에 적용해서는 안 된다.**

3. **서비스 타깃과의 불일치.** 제품 타깃은 운동 초보자·복귀 사용자인데, 헤드라인 PR-AUC 0.7661은 ADVANCED(전체의 43%, PR-AUC 0.8528)가 견인한다. `is_return_mode_candidate` 발생률은 전 분할에서 0.15~0.29%로 **복귀 사용자 표본이 사실상 존재하지 않는다.**

**향후 과제**

- 자체 실사용자 데이터로 제품의 3값 상태(`COMPLETED`/`PARTIAL`/`NOT_COMPLETED`) 재구축 — 현재 이진 타깃은 `PARTIAL`을 표현하지 못한다
- 경험 구간별 임계값 분리 또는 구간별 모델 분리 검토
- 콜드스타트·경험 구간 공정성 지표를 **사전 등록**한 뒤 calibration 재검증
- 하이퍼파라미터 탐색 (본 과제 미수행 영역)
