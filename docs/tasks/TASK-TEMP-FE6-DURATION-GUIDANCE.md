# FE-6 운동 시간 90분 UI와 권장 안내

## 범위

- 체크인 운동 시간 선택 상한을 60분에서 90분으로 확장한다.
- 서버의 일일 체크인 기본값 응답에 포함된 권장 운동 시간을 안내한다.
- 권장 시간보다 긴 선택을 막지 않고 비난하지 않는 안내를 제공한다.
- 90분 계획 구성 실패 시 서버 오류를 보여주며 더 짧은 계획을 대신 표시하지 않는다.

## 변경 계획

1. `DailyContextDefaultsResponse`의 BM-1 추가 필드를 타입에 반영한다.
2. `HomeContainer`에서 서버 권장 시간을 화면과 분리된 체크인 시트에 전달한다.
3. 체크인 시간 스테퍼를 90분까지 확장하고 권장 시간을 안내 전용 정보로 표시한다.
4. 현재 남아 있는 마이페이지 기본 운동 시간 편집의 상한도 90분으로 맞춘다.
5. 서버 응답에 권장 시간이 없는 호환 경로와 90분 실패 경로를 컴포넌트 테스트로 검증한다.

## 계약 및 위험

- 공개 API나 백엔드는 변경하지 않는다. 프론트엔드는 BM-1의 추가 응답 필드만 소비한다.
- 권장 시간은 프론트엔드에서 계산하거나 선택 제한으로 사용하지 않는다.
- 서버가 요청한 시간을 구성할 수 없으면 기존 결정 생성 오류 상태를 사용하며, 이전 또는 축소 루틴을 표시하지 않는다.
- FE-5가 통합되기 전에도 범위가 어긋나지 않도록 현재 마이페이지 편집기는 체크인과 같은 상한을 공유한다. FE-5 통합 후 이 레거시 편집기는 제거될 수 있다.
