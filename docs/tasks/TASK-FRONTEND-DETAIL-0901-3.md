## 배경과 사용자 가치

온보딩, 마이페이지, 운동 카탈로그, 운동 캘린더에서 같은 설정이 서로 다른
용어와 컨트롤로 표시되고 일부 준비 중 기능이 활성 상태처럼 보인다. 사용자가
설정 의미와 기록 상태를 일관되게 이해할 수 있도록 프론트엔드의 세부 UI와 상태
표현을 정리한다.

## 포함 범위

- 온보딩·마이페이지의 운동 시간/주간 횟수 공용 `StepCounter` 사용
- 온보딩·마이페이지·계정 화면의 코칭 스타일 명칭 통일
- 온보딩·체크인·마이페이지의 추가 불편 부위 펼침 컨트롤 통일
- 운동 카탈로그 필터/난이도/장비 표시 개선 및 내부 카탈로그 버전 숨김
- 운동 캘린더의 오늘 표시와 수행 상태 분리, 상태 순서·색상·주차 요약 개선
- 마이페이지의 준비 중 알림 상태, 프로필 편집 저장 피드백,
  로그아웃/회원 탈퇴 구분 개선
- 변경 동작에 대한 컴포넌트 및 모델 테스트

## 제외 범위

- 공개 API 및 Pydantic 계약 변경
- DB 스키마와 마이그레이션
- 백엔드 안전·루틴 결정 로직
- 알림·기기 연동 기능 실제 구현
- 운동 카탈로그 데이터 변경

## 인수 조건

- [x] 같은 코칭 스타일과 운동 수준은 모든 관련 화면에서 같은 한국어 명칭으로
  표시된다.
- [x] 온보딩과 마이페이지의 시간/횟수 증감 컨트롤이 동일하게 동작하고
  최소·최대 범위를 지킨다.
- [x] 오늘 표시는 완료·부분 수행·휴식·미수행 상태와 독립적으로 함께 표시된다.
- [x] 월간·주간 캘린더 상태 순서와 명칭이 일치한다.
- [x] 진행 중 주가 목표 운동 횟수를 달성하면 달성 안내가 표시된다.
- [x] 준비 중 알림 스위치는 꺼짐·비활성 상태이며 준비 중임을 명시한다.
- [x] 운동 카탈로그는 내부 버전을 노출하지 않고 장비가 없는 운동에는 빈 장비
  문구를 표시하지 않는다.
- [x] 프로필 즉시 저장 성공/실패 상태가 사용자에게 전달된다.
- [x] 통증/불편 부위 선택은 안전 입력 의미를 변경하지 않고 기존 코드와 강도
  값을 보존한다.
- [x] 프론트엔드 formatter, linter, type checker, 전체 테스트, production
  build가 통과한다.
