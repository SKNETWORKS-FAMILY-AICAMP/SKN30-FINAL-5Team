## 배경과 사용자 가치

현재 MVP 운동 카탈로그와 안전·대체 관계는 에이전트 검토 DRAFT로 확보되어 있지만,
일반 성인의 주간 신체활동 권고와 강도 구간을 기계가 재현할 수 있는 근거 데이터가 없다.
또한 원천 프로파일에는 미검수 운동 후보가 남아 있어, 새 출처를 무작정 추가하기 전에
현재 카탈로그의 실제 커버리지 공백을 기준으로 후속 검토 대상을 좁힐 필요가 있다.

## 포함 범위

- WHO·CDC·대한민국 질병관리청·Adult Compendium 공식 페이지의 출처 메타데이터 수집
- 일반 성인 대상 주간 유산소·근력 권고와 절대·상대 강도 구간의 보수적 정규화
- 원문 수치, 출처 URL, 조회 시점, 라이선스·사용 제한, 콘텐츠 해시 추적
- 규칙 간 경계값·단위·출처 참조 무결성을 검사하는 fail-closed 검증 도구와 테스트
- 기존 KSPO·wger 원천 프로파일에서 현재 taxonomy로 표현 가능한 후속 검토 후보 선별
- 모든 결과를 `DRAFT`, `AGENT_ONLY`, `production_eligible=false`로 유지

## 제외 범위

- 정식 데이터 수집·전처리 보고서 작성 또는 기존 보고서 갱신
- 특정 운동과 Compendium 활동의 임의 1:1 MET 매핑
- 질환 진단·치료·재활·의학적 운동 처방 규칙
- 사용자 생성 데이터, 웨어러블 원시 데이터, 개인정보·건강 기록 수집
- API, DB schema, migration, 운영 DB 적재
- 새로운 taxonomy 코드나 공개 계약 추가
- 외부 전문가 승인을 받았다고 간주하는 운영 승격
- WHO 원문 PDF 또는 제3자 저작물의 저장소 내 재배포

## 인수 조건

1. 모든 공식 근거는 공급자·URL·조회 시점·라이선스/사용 제한·해시를 가진다.
2. 강도와 주간 권고 수치는 원천별로 분리되고, 상충 값을 임의로 병합하지 않는다.
3. 일반 성인 지침만 구조화하며 개인별 처방으로 해석하지 않는 가드를 포함한다.
4. Compendium MET 값은 변경하지 않고, 운동 카탈로그에 자동 연결하지 않는다.
5. 후속 운동 후보는 기존 검토 배치·카탈로그와 중복되지 않고 선정 근거를 가진다.
6. 모든 산출물은 `DRAFT`, `AGENT_ONLY`, `production_eligible=false`다.
7. 해시 변조·필수 필드 누락·잘못된 경계값·중복 후보를 검증기가 거부한다.
8. 관련 단위 테스트와 전체 데이터 테스트가 통과한다.
9. API와 DB 계약 및 정식 보고서는 변경하지 않는다.

## API 영향

없음. 정규화 결과는 애플리케이션 계약이 아니라 검토용 DRAFT다.

## DB·마이그레이션 영향

없음. FITT 규칙 테이블과 사용자 활동 로그 스키마는 별도 승인 작업으로 남긴다.

## 안전·개인정보·보안 영향

- 일반 인구 집단의 공공 지침만 수집하고 개인 식별자와 사용자 건강 데이터는 다루지 않는다.
- 통증·이상 반응·질환별 규칙을 지침에서 추론하지 않는다.
- 강도 수치는 안전 veto를 대체하지 않으며, 사용자별 처방으로 직접 사용하지 않는다.
- 외부 콘텐츠는 최소한의 사실과 출처 메타데이터만 보존하고 재배포 권리를 넘지 않는다.

## 선행 관계와 차단 요소

- FITT 규칙을 운영에 적용하려면 데이터 모델·서비스 경계·검토 책임의 별도 승인이 필요하다.
- Adult Compendium 활동과 개별 운동 연결에는 별도 매핑 정책과 검토가 필요하다.
- 후속 후보를 카탈로그에 포함하려면 기존 4역할 검토 증적과 안전 규칙 재생성이 필요하다.

## 테스트 계획

- 원천 메타데이터·해시·허용 공급자·URL 검증
- 정규화 강도 경계와 주간 권고 단위 검증
- 원천 사실과 정규화 규칙의 참조 무결성 검증
- 후속 후보 결정의 재현성·비중복·taxonomy 허용 목록 검증
- ruff, format, mypy, 전체 데이터 단위 테스트

## 수동 확인

- 공식 URL이 원 공급자의 현재 페이지를 가리키는지 확인
- 구조화된 수치가 원 페이지와 일치하는지 확인
- 결과가 운영 승인 또는 개인 처방으로 표현되지 않았는지 확인
- 기존 정식 보고서가 변경되지 않았는지 확인

## 알려진 제한과 후속 작업

- 이번 산출물은 근거 DRAFT와 후속 검토 큐다. 운영 적용은 별도 계약 작업이다.
- KDCA·WHO·CDC의 대상 집단과 표현 차이는 병합하지 않고 출처별 사실로 유지한다.
- 웨어러블 데이터는 MVP 필수 수집 대상이 아니며, 실제 사용자 로그는 서비스 구현 이후 수집한다.
