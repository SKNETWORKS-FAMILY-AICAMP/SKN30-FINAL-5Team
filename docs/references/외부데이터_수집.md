## 수집·정규화 경계

`운동지속관리_데이터수집_정리.pdf`의 분리 원칙을 적용한다.

- KSPO에 없는 운동명·장비 메타데이터는 별도 출처 보강 필드로 저장하고 KSPO 제공
  필드처럼 표시하지 않는다.
- 원문 운동 카탈로그, 정규화 운동 마스터, FITT, 안전 규칙, 대체 관계를 서로 분리한다.
- 외부 카탈로그의 설명을 초보자 적합성, 실행 용량, 금기 또는 통증 제외 규칙으로
  자동 변환하지 않는다.
- 대체 운동은 별도 검토 데이터로 관리하며 자동으로 “동일 효과”를 주장하지 않는다.
- 원문 및 프로파일은 `DRAFT`, `production_eligible=false` 상태로 수집한다.
