# ADR-0016: 외부 캘린더 연동 및 당일 유산소 선택 폐기

- 상태: ACCEPTED
- 날짜: 2026-09-02
- 소유자: 제품·개발 공동
- 승인 근거: 사용자 명시 요청(2026-09-02)
- 대체 대상: ADR-0006, ADR-0010의 외부 캘린더 계약

## 결정

- 외부 캘린더 제공자 연결, 일정 조회·등록, 수행 여부 확인과 관련 동의·API·저장 계약을 서비스 범위에서 제거한다.
- Daily Check-in에서 유산소 포함 여부를 선택하는 입력과 그에 따른 제약을 제거한다.
- 유산소 구성은 사용자의 목표, 회복 상태와 검수된 운동 풀에 따라 시스템이 결정한다.
- 앱 내부의 운동 기록 월간 캘린더는 외부 연동이 아니므로 유지한다.

## 영향

ADR-0006과 ADR-0010은 역사 기록으로만 보존하며, 외부 캘린더에 관한 모든 운영 계약은 더 이상 적용하지 않는다. 기존 공개 API·DB 구현에 남아 있는 폐기 대상은 별도 호환성·migration 작업으로 제거한다.
