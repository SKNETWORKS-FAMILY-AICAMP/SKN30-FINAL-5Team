# Architecture Decision Records

기존 계약만으로 답할 수 없는 구조적 결정을 기록한다.

파일명은 `NNNN-short-title.md`를 사용한다. 상태는 `PROPOSED`, `ACCEPTED`, `SUPERSEDED`, `REJECTED` 중 하나다. 채택된 결정을 바꿀 때 이전 ADR을 삭제하지 않고 새 ADR에서 `SUPERSEDED` 관계를 남긴다.

ADR은 배경, 결정, 이유, 대안, 선택하지 않은 이유, 결과, 미확정 사항, 승인자를 포함한다. `TEMPLATE.md`를 복사해 사용한다.
