# ADR-0004: 안전·칼로리·개인정보 보존 정책 기준

- 상태: ACCEPTED
- 날짜: 2026-08-11
- 소유자: 제품·개발 공동
- 승인자: PM + 개발팀장 + 외부 도메인·개인정보 검토(최종 승인)
- 승인 증적: 사용자 명시 승인(2026-08-11, 본 작업 요청). PR 링크는 생성 후 연결
- 관련 요구사항/이슈: `F004`, `POL-008`~`POL-013`, `NFR-003`~`NFR-005`

## 관계

- `ADR-0007`은 본 ADR의 멀티 에이전트 안전 게이트 구조 중 `FinalSafetyGate` 관련 결정만 부분 대체한다.
- 안전·칼로리 추정·동의·개인정보 보존·삭제에 관한 나머지 결정은 본 ADR을 계속 적용한다.

## 배경

요구사항 정의서와 문서의 정합성을 위해 안전 상태, 체중 기반 칼로리 추정, 동의 철회, 보존·삭제 정책을 문서에 반영했다. 산식과 법률·도메인 검토는 아직 남아 있다.

## 결정

- 예상 소모 칼로리는 운동 종류·시간·강도와 사용자 체중 기반 추정치로만 제공한다.
- 체중이 없거나 계산에 실패하면 추정값을 만들지 않고 `null` 또는 `UNKNOWN/FAILED` 상태로 처리한다.
- 칼로리 추정치는 진단·안전 판정의 단독 근거로 사용하지 않는다.
- 안전 상태는 결정적 SafetyPolicyEngine이 envelope와 승인 pool로 고정하고, compiler 뒤 integrity validator가 compiled plan을 검증한다. 필수 처리 실패 시 계획을 반환하지 않는다.
- 일반·민감·웨어러블·마케팅 개인정보 consent 네 코드를 분리하고 철회 시 해당 처리와 동기화를 중단한다. 서비스 이용약관 동의는 별도 약관 버전·시각 이력으로 관리하며 개인정보처리방침은 별도 동의 코드 없이 열람만 제공한다.
- 체크인·웨어러블 원본·요약·수행·리포트의 보존·삭제 기준을 적용하며, 법률상 예외가 확인되면 새 ADR로 변경한다.
- 승인된 기본 보유기간은 체크인 28일, 웨어러블 원본 24시간, 일별 요약·상세 수행·설문 90일, 주간 리포트 12개월, 운영 DB 삭제 7일, 백업 순환 30일, 관리자 접속기록 2년, 마스킹 오류 로그 7일이다.

## 결정 이유

요구사항의 안전·개인정보·칼로리 제약을 누락 없이 반영하면서, 확정되지 않은 산식과 보존 법적 기준을 조기에 고정하지 않기 위해서다.

## 검토한 대안

- 웨어러블 칼로리를 실제값으로 취급
- 칼로리 추정치를 안전 판정에 사용
- 모든 동의를 하나의 동의값으로 저장
- 원본 건강·웨어러블 데이터를 장기 보존

## 선택하지 않은 대안과 이유

- 웨어러블 값은 출처·오차·누락이 있어 단독 기준으로 부적절하다.
- 칼로리는 추정치이므로 안전·의료 판단에 사용하면 오용 위험이 있다.
- 동의 통합 저장은 철회 범위를 분리할 수 없다.
- 원본 장기 보존은 최소 수집·보존 원칙과 충돌한다.

## 결과와 영향

관련 문서는 이 ADR을 승인된 안전·칼로리·보존 기본선으로 사용한다. 아직 정하지 않은 산식·임계값과 법률상 예외는 해당 구현 전에 별도 승인을 받고, 기본선을 바꾸면 새 ADR을 작성한다.

## 보안·개인정보·호환성 영향

직접 식별자, 원시 건강·웨어러블 샘플, 인증 토큰을 로그나 LLM에 전달하지 않는다. 동의 철회·계정 삭제·백업 만료 절차가 API·DB·운영 작업에 영향을 준다.

## 아직 확정되지 않은 사항

- 칼로리 산식·계수·단위·반올림·버전
- 피로·수면·복귀 임계값과 안전 문구


## 후속 작업

1. 데이터 항목과 출처를 확정한다.
2. 확정 데이터를 기준으로 에이전트 로직과 안전 테스트를 설계한다.
3. 개발 단계에서 산식·정책·API·DB·테스트를 함께 승인한다.
