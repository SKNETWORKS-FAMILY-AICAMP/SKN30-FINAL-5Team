# 바나나 받기 미니게임

끼끼의 집에서 여는 독립형 30초 캐치 게임이다. 게임 점수와 최고 기록은 저장하지
않지만, 완료 점수는 모든 미니게임이 공유하는 하루 한 번의 바나나 보너스에 사용한다.

- `bananaCatchModel.ts`: 화면 크기와 무관한 상대 좌표, 낙하·포획·종료 규칙
- `BananaCatchGameScreen.tsx`: 타이머, 터치·버튼 입력, 일시정지와 화면 표시
- 라운드를 시작할 때 낙하·생성 속도를 함께 정하며, 기존 속도의 100~125% 범위에서 매 라운드 달라진다.
- 떨어지는 바나나는 생성될 때 서로 다른 각도와 완만한 회전 속도를 받는다.
- 바나나는 장면 오브젝트의 최상단 레이어에서 떨어지고, 바나나 하단이 바구니 윗선에
  닿을 때 획득된다.
- 끼끼는 0–9개에서 빈 바구니, 10–19개에서 중간 바구니, 20개 이상에서 가득 찬
  바구니 에셋을 사용한다. 세 에셋을 미리 겹쳐 렌더링하고 투명도만 바꿔 전환 시
  디코딩 공백을 방지한다.
- 장면 배경은 화면 전체를 `cover`로 채우며 별도의 내부 게임 프레임을 두지 않는다.
  HUD 아래 전체 너비가 게임장이며, 투명 PNG 잔디 바닥은 화면 맨 아래까지 이어진다.
  기존 포획선과 끼끼의 위치 비율은 유지한다.
- 하단 이동 버튼은 두지 않으며, 전체 게임장을 누르거나 드래그해 끼끼를 움직인다.
- 점수와 최고 기록은 저장하지 않는다.
- 놓친 바나나는 감점하지 않으며 실패·압박 문구를 표시하지 않는다.
- 앱이 비활성화되면 진행을 멈추고 사용자가 직접 이어서 시작한다.

규칙 검증은 `tests/bananaCatchModel.test.ts`, 화면과 타이머 검증은
`tests/BananaCatchGameScreen.test.tsx`에 둔다.
