# 개인정보처리방침

## 1. 운영주체와 서비스 성격

운영주체는 **SK Networks Family AI Camp 30기 Final 5팀 콩닥**입니다. 본 서비스는 SK Networks
Family AI Camp 교육 과정에서 제작한 비상업적 교육 및 포트폴리오 프로젝트로, 실제 의료·헬스케어
사업자가 제공하는 상용 서비스가 아닙니다. 프로젝트 운영 종료 예정일은 **2026년 9월 18일**입니다.

## 2. 개인정보를 처리하는 목적

운영팀은 계정·프로필 관리, 만 18세 이상 64세 이하의 일반 성인에 대한 서비스 이용 가능 연령 및
자동 운동 계획 지원 범위 확인, 개인화 운동 계획·기록·주간 리포트 제공, 예상 소모 칼로리 제공 및
안전한 운동 조정을 위해 개인정보를 처리합니다. 질환·임신 등으로 개별적인 운동 관리가 필요하거나
의료진에게 운동 제한 또는 주의 안내를 받은 이용자는 자동 운동 계획 지원 대상이 아닙니다.

## 3. 처리하는 개인정보 항목

| 구분 | 처리 항목 |
|---|---|
| 회원 및 인증정보 | 닉네임, 소셜로그인 제공자(Google, Kakao), 제공자 식별정보, 생년월일 |
| 운동 프로필 정보 | 체중, 운동 목표, 운동 경험 수준, 주간 목표 운동 횟수, 기기 설정에서 자동 수집되는 시간대 |
| 운동 환경정보 | 당일 운동 장소, 당일 운동 가능 시간 |
| 건강·안전 관련 민감정보 | 질환·임신 등 개별 관리 필요 여부, 의료진 운동 제한·주의 안내 여부, 지속 통증 부위 및 강도, 당일 통증 부위 및 강도, 피로도, 수면 관련 정보, 운동 위험 신호, 운동 중·후 통증 및 이상반응, 안전상 중단 여부 |
| 서비스 이용정보 | 생성된 운동 계획, 운동 수행 기록, 운동 완료 여부, 운동 후 피드백, 미수행 사유, 주간 리포트 |
| 선택 정보 | 이용자가 등록한 프로필 이미지 |
| 동의 이력 | 동의 종류, 동의 여부, 동의 버전 및 시각 |

이메일 주소, 이름, OAuth 프로필 이미지 및 그 밖의 OAuth claim은 현재 사용자 DB에 저장하지 않습니다.
키, 성별, 관심 신체 부위, 선호 운동 유형, 웨어러블 정보 및 캘린더 정보는 수집항목에 포함하지
않습니다. 서비스는 질환명, 진단명, 상세 병력 또는 자유서술 의료정보를 수집하지 않습니다.

## 4. 민감정보 처리

민감정보는 일반 개인정보 동의와 분리하여 필요한 최소 범위에서 처리합니다. 운동 제한·주의 여부,
통증·피로·수면·위험 신호·이상반응은 위험할 수 있는 운동을 제외하고 강도와 구성을 조절하며, 당일
컨디션을 반영한 계획 및 운동 중단 또는 전문가 상담이 필요한 상황을 안내하기 위해 이용합니다.

## 5. 생성형 AI 및 외부 서비스 이용

운영팀은 운동 계획 구성 및 선택적으로 주간 리포트 안내 문구를 생성하기 위해 OpenAI API를 이용할 수
있습니다. V3 운동 계획 생성 시 OpenAI에는 요청 운동시간, 운동 목표·장소 코드, 회복 상한, 안전 조치
코드 및 승인 운동 카탈로그의 비민감 코드·UUID·시간 기준만 전송됩니다. 주간 리포트 안내에는 식별자와
자유서술을 제외한 완료·중단 건수, 완료율, 미수행 사유 코드, 조정 방향 코드 등 집계된 기계 코드와
수치만 전송됩니다. 사용자 ID, 닉네임, 이메일, 소셜로그인 식별정보, 정확한 생년월일, 체중, 원시
통증·피로·수면정보, 운동 제한 여부 및 원시 운동 수행기록은 OpenAI에 전송하지 않습니다.

| 외부 서비스 | 확인된 이용 범위 |
|---|---|
| Amazon Web Services | AWS 서울 리전(ap-northeast-2)의 Aurora PostgreSQL에 서비스 데이터를, S3에 이용자가 등록한 프로필 이미지를 저장합니다. Secrets Manager와 KMS는 비밀정보 및 생년월일 암호화에 사용합니다. |
| Firebase Authentication | Firebase ID Token 검증과 Firebase custom token 발급에 사용합니다. 서비스 DB에는 인증 제공자의 subject만 계정 식별정보로 저장합니다. |
| Kakao | Kakao 로그인과 계정 연결에 사용합니다. 서비스 DB에는 제공자 코드와 검증된 subject만 계정 식별정보로 저장합니다. |
| OpenAI API | 위 최소화된 구조화 코드·수치와 승인 운동 카탈로그 정보만 API 요청으로 전송합니다. 외부 추적 서비스로 프롬프트 본문을 보내지 않도록 LangSmith tracing과 callbacks를 비활성화합니다. |

웨어러블 및 캘린더 연동 기능은 현재 제공하지 않으며 관련 정보를 처리하지 않습니다.

## 6. 보유기간과 파기 절차·방법

수집된 개인정보 및 민감정보는 서비스 제공을 위해 프로젝트 운영기간 동안 보관합니다. 프로젝트 운영
종료일은 **2026년 9월 18일**이며, 별도의 보관 필요성이 없는 정보는 원칙적으로 프로젝트 종료일로부터
30일 이내 파기합니다. 프로젝트가 조기 종료되거나 운영이 중단되는 경우에는 개인정보 처리 목적이
소멸한 시점을 기준으로 같은 파기 원칙을 적용합니다. 이용자의 회원 탈퇴, 개인정보 삭제 또는 동의
철회 요청이 있으면 서비스 제공에 더 이상 필요하지 않은 정보를 지체 없이 파기합니다.

운영팀은 보유기간이 경과하거나 처리 목적이 달성된 경우 해당 개인정보를 지체 없이 파기합니다. 전자적
파일은 복구 또는 재생이 어렵도록 삭제하며, 별도 문서 형태로 보관하는 정보가 있으면 파쇄 또는 안전한
방법으로 폐기합니다. 법령상 별도 보관이 실제로 필요한 정보가 있는 경우에만 해당 법령상 기간 동안
보관합니다.

## 8. 개인정보 보호조치

운영팀은 인증된 사용자만 자신의 개인정보에 접근하도록 하고, 생년월일은 AWS KMS를 사용해 암호화하여
저장합니다. AWS Secrets Manager로 배포 비밀정보를 주입하고, Caddy의 TLS를 통해 전송구간을
보호합니다. 데이터베이스와 내부 API 포트는 외부에 직접 공개하지 않으며, 인증 토큰·이메일·전체 이름·
원시 건강정보·LLM 요청 및 응답 본문을 로그에 남기지 않도록 구현합니다.
