## 1. 수집 개요와 완료 판단

본 프로젝트는 운동 초보자와 복귀 사용자를 위한 개인화 운동 지속 관리 서비스다. 대량
학습용 데이터셋을 만드는 대신, LLM의 임의 추천을 제한할 운동 후보·공중보건 기준·강도
기준과 결정적 안전·대체 규칙의 근거 데이터를 수집했다.

2026-08-11 기준 MVP 외부 수집은 마감 가능하다. 운동 카탈로그 56건, 일반 성인 FITT
근거 10건, 강도 분류 규칙, Adult Compendium 관련 활동 20건을 확보했고, 모든 원천에
출처·수집 시각·라이선스·SHA-256을 남겼다. 이는 모든 운동을 수집했다는 뜻이 아니며,
현재 서비스 범위에서 필요한 검증 가능한 최소 풀을 확보했다는 의미다.

| 데이터 | 수집 범위 | 수집 목적 | 출처·권리 처리 |

KSPO 원천 스냅샷 매니페스트 SHA-256은
`45e22195f521b7279a6383df37660296628a0e0d159b0ccef55b2cbaacde885f`, wger는
`fb178cd11719130b1784a788cd098f08db1e97102e75ebf58d6d26822b6bab75`다.

## 3. 수집 방식과 저장

- 수집 방식: 공공·공개 API 호출, 공식 웹 문서/PDF 확인, HTTP 응답 또는 구조화 사실 해시
- 자동화: 수집·프로파일·검토·시드 생성·검증 스크립트를 단계별로 실행하며, 네트워크
  원천을 매 실행 시 덮어쓰지 않고 시점별 불변 스냅샷으로 저장
- 예외 처리: 페이지·리소스·필수 필드·해시가 맞지 않으면 실패하고 부분 산출물을 최종
  디렉터리로 승격하지 않는 fail-closed 방식
- 인코딩/포맷: UTF-8 JSON, JSONL, CSV, Markdown, DOCX

저장 계층은 다음과 같이 분리했다.

| 계층 | 경로 | 내용 |
|---|---|---|
| 원천 | `data/raw/` | 변경하지 않는 API·공식 문서 스냅샷과 출처·라이선스 메타데이터 |
| 정규화 | `data/normalized/` | taxonomy, 검토 결정, FITT·강도 참고, 안전·대체 정책 |
| 생성 | `data/generated/` | 운동 카탈로그 시드, 안전 규칙, 대체 관계 |
| 검증 | `data/validation/` | 프로파일, 리뷰 증적, 골든 시나리오 결과 |

## 4. 원천 품질 분석

### KSPO

- 프레임 1,668행을 파일-운동명 후보 단위로 재구성했다.
- 고유 동영상 243개, 운동명 있는 후보 쌍 391개, MVP 범위 후보 231개다.
- 한 동영상에 여러 운동명이 연결된 경우가 49개이므로 파일 하나를 운동 하나로 보지 않았다.
- 운동명 누락 원천 행 15개는 후보에서 제외했다.
- 도구·세트·반복·시간·주기 누락률이 높아 원천 처방량을 서비스 기본값으로 사용하지 않았다.

### wger

- 862개 운동 중 영어 번역 보유 849개, 한국어 번역 보유 0개다.
- 헬스장 검토 후보 400개 중 장비 근거 후보는 377개다.
- 이미지 참조 266개, 영상 참조 46개는 URL 메타데이터만 보존했다.
- 커뮤니티 설명과 근육 정보는 초보 적합성·실행 지침·금기 규칙으로 자동 변환하지 않았다.

## 5. 검토와 최종 수집 결과

초기 KSPO 50건·wger 60건과 보강 tranche 11건, 총 121건을 INCLUDE/EXCLUDE로 완전
분할했다. 미결은 0건이다.

| 원천 | 검토 | 포함 | 제외 | 미결 |
|---|---:|---:|---:|---:|
| KSPO | 57 | 26 | 31 | 0 |
| wger | 64 | 30 | 34 | 0 |
| 합계 | 121 | 56 | 65 | 0 |

최종 56개는 근력 50, 유산소 2, 모빌리티 4이며 상체 26, 하체 20, 코어 7, 전신
3으로 구성된다. 위치 태그는 헬스장 32, 홈 24, 야외 1이며 다중 위치를 허용한다.

## 6. 법적·윤리적 검토

- 개인정보·사용자 건강기록·GPS·웨어러블 원시값·인증정보는 수집하지 않았다.
- API 키와 토큰을 원천·매니페스트·보고서에 저장하지 않았다.
- 원천 동영상·이미지 바이너리를 재배포하지 않는다.
- wger 항목별 라이선스·저자 표시와 WHO/CDC/KDCA/Compendium 사용 조건을 보존했다.
- 외부 운동·의료 전문가 승인이 없으므로 결과를 진단·치료·재활·처방에 사용하지 않는다.

## 7. 품질·정합성 관리

- 파일별 SHA-256, 바이트 수, 레코드 수를 매니페스트와 대조한다.
- 원천 ID와 stable code 중복, 필수 필드 누락, 허용 taxonomy 위반을 실패 처리한다.
- 원천·정규화·생성 데이터를 분리하고 기존 산출물을 덮어쓰지 않는다.
- 네 역할 에이전트 검토 증적과 INCLUDE/EXCLUDE 근거를 보존한다.
- 전체 데이터 테스트 121건, ruff format/check, mypy를 통과했다.
- 안전 규칙·대체 관계·골든 결과 3세트 8개 파일의 재생성 결과가 바이트 단위로 동일했다.

## 8. 추가 수집 판단과 제한

현재는 새로운 외부 출처를 추가하지 않는다. 카탈로그가 근력 50, 이동성 4, 유산소
2로 치우쳐 있으므로 걷기 외 유산소 또는 추가 이동성 유형이 제품 인수 조건이 되거나,
사용자 테스트에서 장소·장비·목표 공백이 확인될 때만 표적 수집한다. 먼저 기존 KSPO
231개 MVP 후보와 wger 400개 헬스장 후보의 미선정 영역을 재검토하고, 부족할 때만 세
번째 출처를 도입한다.

사용자 프로필·체크인·수행 결과·미수행 사유·에이전트 협상 로그는 서비스 발생 데이터이므로
기능과 저장 계약이 구현된 이후 수집한다. 모든 현재 결과는 `AGENT_ONLY`,
`production_eligible=false`이며 운영 DB에는 적재하지 않았다.
