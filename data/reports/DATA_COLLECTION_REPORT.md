## 3. 원천 품질 프로파일

### KSPO

- 프레임 단위 1,668행을 파일·운동명 단위로 재구성했다.
- 고유 동영상 파일 243개, 운동명 있는 파일-운동 쌍 391개다.
- MVP 범위 후보 231개, 범위 밖 후보 160개로 분리했다.
- 한 동영상에 여러 운동명이 매핑된 경우가 49개이므로 파일 하나를 운동 하나로 간주하지 않았다.
- 운동명 누락 원천 행은 15개이며 후보 생성에서 제외했다.
- 주요 누락률은 도구 23.98%, 세트 83.87%, 반복 84.65%, 시간 85.43%, 주기 86.39%,

## 4. 검토 표본과 수집 완료 판단

전체 프로파일에서 MVP 우선순위로 KSPO 50개와 wger 60개, 총 110개를 리뷰 배치로
선정했다. 모든 110개에 대해 포함 또는 제외 결정을 완료했으며 미결은 0개다.

| 원천 | 리뷰 배치 | 포함 | 제외 | 미결 |
|---|---:|---:|---:|---:|
| KSPO | 50 | 23 | 27 | 0 |
| wger | 60 | 27 | 33 | 0 |
| 합계 | 110 | 50 | 60 | 0 |

현재 50개 카탈로그의 운동 유형은 근력 45, 유산소 2, 모빌리티 3이고, 위치 태그는
헬스장 29, 홈 21, 야외 1이다. 하나의 운동이 여러 위치를 가질 수 있어 위치 합계는
운동 수와 다를 수 있다.

이 범위는 MVP의 일상 컨디션 기반 루틴 생성과 결정 규칙 검증에는 충분하다. 따라서
**지금은 추가 수집을 중단하고 품질 검증 단계로 이동**한다.

## 5. 추가 수집 재개 조건

다음 중 하나가 실제 테스트·운영 지표로 확인될 때만 추가 수집을 재개한다.

1. 필수 루틴 시나리오에서 안전 필터 적용 후 선택 가능한 운동이 3개 미만이다.
2. 홈/헬스장, 장비 없음/보유 장비 조건 중 하나에서 2개 이상의 움직임 패턴이 비게 된다.
3. 동일 부위·목표의 대체 운동을 최소 2개 제공하지 못한다.
4. 실제 사용자 요청에서 현재 taxonomy로 표현할 수 없는 운동 유형이 반복된다.
5. 유산소 다양성, 균형·민첩성 등 현재 부족 영역이 제품 요구사항으로 확정된다.
6. 라이선스 또는 원천 변경으로 현재 운동을 제거해야 한다.

재수집 시에는 먼저 기존 KSPO 231개 MVP 후보와 wger 400개 헬스장 후보의 미선정 영역을
확장한다. 이 풀로도 결손이 해결되지 않을 때만 세 번째 원천을 도입한다.

## 6. 보안·개인정보·권리 점검

- API 키와 인증 토큰은 스냅샷·매니페스트에 저장하지 않았다.
- 사용자 건강정보, 이메일, 이름, GPS, 웨어러블 원시 데이터는 수집 대상이 아니다.
- wger 원천의 공개 기여자 표시는 라이선스 귀속을 위해 원천 메타데이터에 존재할 수 있다.
  서비스 입력이나 LLM 컨텍스트로 보내지 않고, 배포 전에는 표시명과 필요한 귀속 정보만
  최소화해 별도 라이선스 레지스트리로 분리해야 한다.
- 원천 영상·이미지 바이너리는 수집하지 않았다.

## 7. 제한 사항

- 결과는 외부 운동·의료 전문가 승인이 아닌 에이전트 단독 DRAFT 검토다.
- 한국어 운동명·지침은 원문 복사가 아니라 보수적으로 새로 작성했으나 전문 감수본은 아니다.
- 최종 카탈로그는 아직 운영 DB에 적재하지 않았고 production 사용이 금지돼 있다.
- 유산소 2개와 모빌리티 3개로 유형 다양성이 근력보다 낮다. 현재 MVP에는 허용하지만,
  루틴 테스트에서 결손이 확인되면 가장 먼저 보강한다.
