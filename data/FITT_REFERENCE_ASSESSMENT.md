# FITT·강도 참고 원천 평가

상태: `DRAFT`
평가일: 2026-08-11
프로덕션 사용 가능: `false`
승인 필요: PM·법무(라이선스), 도메인 검토자(수치 적용)

## 1. 결론

`docs/references/외부데이터_수집.md`의 미수집 원천 3건을 평가했다. **세 원천 모두 KSPO·wger
처럼 snapshot으로 수집하지 않는다.** 공개 API나 데이터셋이 아니라 저작권이 있는 논문·웹
문서이며, MVP 스키마가 이들 데이터를 컬럼으로 요구하지도 않는다.

수집 파이프라인을 만드는 대신 **정책 수치의 근거로 인용**하고, 실제 값은 도메인 검토자가
검수 데이터로 작성한다.

## 2. 원천별 평가

### 2.1 2024 Adult Compendium (MET)

- 제공 형태: PDF 및 논문. CSV·Excel·API 없음.
- 규모: 활동 1,114종, 측정 MET 912종.
- 라이선스: 논문은 CC BY-NC-ND 4.0. 사이트 이용 안내는 인용을 요구하며
  **"MET 값을 변경하거나 서로 다른 MET 활동을 합치지 말 것"** 을 명시한다.
- 상업적 이용 가능 여부에 대해 논문 라이선스(NC)와 사이트 안내가 서로 다르게 읽힌다.
  적용 전 PM·법무 확인이 필요하다.

**판단: 수집하지 않는다. 단, 아래 근거는 갱신되었다.**

최초 판단의 근거는 "`docs/DATA_MODEL.md`에 MET 컬럼이 없다"였다. **이 전제는 2026-08-11
develop 병합으로 무효가 되었다.** 병합된 문서에는 `estimated_calories_burned` 4개,
`calculation_version` 1개가 있고 `docs/DOMAIN_RULES.md` 258행이 "예상 소모 칼로리 산식과
계수는 버전 관리하며 개발 전 확정한다"고 요구한다.

그럼에도 수집하지 않는 이유는 바뀌지 않았다. 라이선스가 CC BY-NC-ND이고 상업적 이용
가능 여부가 불확실하다.

**칼로리 산식·계수는 개발 리드 결정으로 데이터 파트 범위에서 제외한다(2026-08-11).**
`docs/API_CONTRACT.md` 1111행과 `docs/adr/0001` 100행의 미확정 항목으로 남으며, 담당
배정은 이 문서가 정하지 않는다.

참고로 확인한 스키마 공백을 남긴다. 칼로리 **결과**를 저장할 컬럼과 `calculation_version`
포인터는 있으나 **산식·계수 자체를 담을 테이블이 없다.** `policy_versions`에도
`duration_rule_version`·`safety_rule_version`만 있고 칼로리 버전은 없다.

### 2.2 ACSM·ESSA 강도 합의문

- 제공 형태: ScienceDirect 학술 논문. 유료 접근.
- 용도: 상대 강도·체감 노력 분류의 학술 근거.

**판단: 수집 대상 아님.** 유료 논문을 크롤링하지 않는다. `intensity_code`의 등급 정의를
정할 때 참고 문헌으로 인용한다.

### 2.3 질병관리청 신체활동 정보

- 제공 형태: 공공 웹 문서.
- 성인(19~64세) 권고 수치
  - 중강도 유산소 주 150~300분 **또는** 고강도 주 75~150분
  - 고강도 1분 = 중강도 2분
  - 근력 운동 주 2일 이상, 세트당 8~12회
  - 좌식 시간 최소화
- 라이선스: **공공누리 제4유형(출처표시 + 상업적 이용금지 + 변경금지).**

**판단: 주의 필요.** KSPO(제1유형)와 달리 제4유형은 상업적 이용과 변경을 금지한다.
권고 **수치 자체는 사실이므로 출처를 밝히고 정책 근거로 인용**할 수 있으나, 페이지의
문장·표·이미지를 그대로 복제하거나 변형해 제품에 넣지 않는다. 서비스가 상업적 성격을
가질 경우의 인용 범위는 PM·법무가 확인한다.

## 3. MVP 스키마가 실제로 요구하는 것

앞선 상황 보고에서 FITT 근거 부재를 실제보다 넓게 적었다. 확인 결과 세션 시간 구조는
이미 정책으로 확정되어 있다.

`docs/DOMAIN_RULES.md`에 확정된 값:

| 구간 | 값 | 출처 |
|---|---|---|
| 장비 준비 | 0~60초 | DOMAIN_RULES |
| 준비 운동 | 60~180초 | DOMAIN_RULES |
| 동작 전환 | 동작당 10~20초 | DOMAIN_RULES, DATA_MODEL |
| 마무리 | 45~120초 | DOMAIN_RULES |
| 세트 간 휴식 | **운동 데이터에 정의** | 미작성 |

따라서 외부 원천이 필요한 항목은 없고, 카탈로그에서 사람이 작성해야 하는 항목만 남는다.

- `timing_mode_code` (REPS 또는 DURATION)
- `default_seconds_per_rep` 또는 `default_work_seconds`
- `default_rest_seconds`
- `difficulty_code`, `beginner_suitable`
- `recovery_eligible`

질병관리청의 "세트당 8~12회"는 근력 운동 반복수 기본값을 정할 때 인용 가능한 근거다.
개별 운동의 세트·반복·휴식은 여전히 도메인 검토자가 확정한다.
