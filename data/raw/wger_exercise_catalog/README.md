# wger exercise catalog metadata

wger의 공개 REST API에서 운동 카탈로그와 참조 코드를 JSON으로 수집한다. 목적은
국민체력100에서 식별하기 어려운 헬스장 기구·프리웨이트 운동의 명칭, 장비, 근육 및
분류 후보를 보강하는 것이다.

- 공개 조회에는 API 키가 필요하지 않는다.
- 운동·번역·이미지 등은 항목별 라이선스가 다를 수 있으므로 각 응답의 라이선스 정보를
  그대로 보존한다.
- 이미지·동영상 파일은 다운로드하지 않고 URL 메타데이터만 보존한다.
- 커뮤니티 설명을 안전 규칙, 초보자 적합성 또는 실행 처방으로 자동 승격하지 않는다.
- 수집 결과는 항상 `DRAFT`, `production_eligible=false`다.

로컬 snapshot은 `snapshots/` 아래에 생성되며 기본적으로 Git에서 제외된다.
